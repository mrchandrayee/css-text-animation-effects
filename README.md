A responsive recreation of the uploaded 26.4-second video. It contains five animated text styles and the corresponding CSS snippets in expandable code panels.

## Effects
1. Liquid Gradient — CREATIVE
2. Cyber Glitch — FUTURE
3. 3D Wave — ANIMATED
4. Mask Reveal — DISCOVER
5. Neon Electric — ELECTRIC

## Features
- Dark theme with blue glowing page heading
- Five individual preview cards
- CSS code snippet shown below each effect
- Copy CSS button for each effect
- Replay all animations button
- Responsive mobile layout

## Run
No dependencies or build process required.

```bash
python -m http.server 8000
```

Open http://localhost:8000

## Files
- `index.html` — page structure and previews
- `style.css` — all five animation effects and layout
- `script.js` — code snippet rendering, copy actions and replay
- `README.md` — setup notes

## Extraction note
The video visibly shows the five effect names and substantial CSS sections. This project transcribes the readable concepts and recreates the effects in a complete runnable implementation. Some supporting declarations and page structure are reconstructed; this is not the original creator's unseen source verbatim.
